# US-008 — Allow Manager/Admin Override with Warning

**As a** manager,  
**I want** to optionally save an allocation even when it causes temporary over-allocation,  
**so that** exceptional business needs can be recorded while still being visible as a warning.

## Acceptance Criteria

1. **Given** a user with a manager/admin role submits an allocation that causes over-allocation,  
   **When** the system detects the conflict,  
   **Then** it shows a warning and provides an “Override and save” option.

2. **Given** the override option is used,  
   **When** the allocation is saved,  
   **Then** the allocation is persisted and visually flagged (e.g., badge or highlight) as over-allocated.

3. **Given** a non-manager user attempts to create an over-allocation,  
   **When** the system detects the conflict,  
   **Then** only a hard block is shown with no override option.

## Priority

Could-have / Won’t-have for initial release

## Notes / Open Questions

- The schema currently has no user/role table; this story depends on introducing authentication and authorization.
- Should overridden over-allocations appear on a dedicated report or dashboard widget?
