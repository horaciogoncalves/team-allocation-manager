# US-007 — Show Allocation Capacity Preview Before Saving

**As a** team lead,  
**I want** the allocation form to show me the member’s current capacity during the selected date range before I submit,  
**so that** I can proactively avoid conflicts.

## Acceptance Criteria

1. **Given** I select a member and date range in the allocation form,  
   **When** the form has those values,  
   **Then** a summary displays the total existing allocation percentage for that range and the remaining available capacity.

2. **Given** the selected range would leave less than 0% capacity,  
   **When** the preview is rendered,  
   **Then** it is styled as an error/warning before submission.

3. **Given** the selected member has no date range entered,  
   **When** the preview is rendered,  
   **Then** it treats the range as indefinite and shows the member’s lifetime total allocation.

## Priority

Should-have

## Notes / Open Questions

- Does the preview require an additional API endpoint, or can it reuse the existing allocations list?
